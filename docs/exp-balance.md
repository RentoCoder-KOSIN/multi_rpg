# 経験値バランスの基準

## レベルアップに必要な経験値
`maxExp(L) = 100 × L²`（client/entities/Player.js の calcMaxExp）

## 敵の経験値（server/data/enemyStats.js の exp）
「同じレベルの敵を何体倒すと1レベル上がるか」を基準に決める。

    exp = 100 × L² ÷ 倒す体数

| 種類 | 倒す体数 | 備考 |
|------|----------|------|
| 通常の敵 Lv〜94 | 約11体 | 既存の値。実際は敵経験値補正(×0.35)がかかるので約31体 |
| 通常の敵 Lv100〜 | 11 + (L-90)×0.04 体 | Lv200で約15体。終盤ほど少しだけ重くする |
| ボス | 2体 | Lv30〜66の既存ボスと同じ比率 |

Lv100以上の敵は以前、上の式の100〜1000倍の経験値になっていた
（ドラゴン1体で数十レベル上がるなど）。

## クエストの経験値（client/data/quests.js の reward.exp）
受け取り時に ×10（GROWTH_CONFIG.QUEST_EXP_MULTIPLIER）される。目安は「そのクエストのレベル帯で何レベル分か」。

    reward.exp = 目安レベル数 × 10 × L²      （L = 討伐対象の敵レベル）

| 種類 | 目安 |
|------|------|
| 入門の討伐（kill_*） | 0.6〜0.8レベル |
| 通常の討伐（*_hunt） | 約1.0〜1.2レベル |
| 大量討伐（extermination / hero / buster） | 1.5〜2.0レベル |
| ボス討伐（メイン） | 2.0〜3.0レベル（最終ボスは4.0） |
| ユニーク（ドラゴン連戦など） | 2.5〜4.0レベル |

## 無限の深淵（server/data/abyssFloors.js）
- 敵1体: 敵レベル（20 + 階層×2）の通常の敵と同じ（約11体で1レベル）
- 階層クリア: `100 × 敵レベル² × 0.25`。gainExp に敵レベルを渡すので、格下の階層の周回にはレベル差補正がかかる
- 以前は階層に対して指数（1.08^階 / 1.15^階）で増えていた
