MULTI RPG 機能・コンテンツ一覧
更新日: 2026-10-04

このファイルは、現時点で実装されているゲーム機能、操作、マルチプレイ、コンテンツを
まとめた運用・確認用の一覧です。数値や個別のスキル／アイテム定義は client/data/ を参照します。

======================================================================
1. ゲームの基本
======================================================================
- ブラウザで動く2D見下ろし型アクションRPG。
- アカウント登録／ログイン方式。セーブデータはアカウントごとにサーバーへ保存。
- 同一アカウントの多重ログイン時は古い接続を切断し、セーブの上書きを防止。
- PCとモバイルに対応。モバイルでは仮想パッドとタップ移動を利用可能。
- BGM、各種エフェクト、ミニマップ、プレイヤー名・HP表示、通知表示を搭載。
- 死亡、HP/MP自然回復、レベルアップ、経験値・ゴールド・ドロップ獲得を実装。

======================================================================
2. 操作方法
======================================================================
- 矢印キー: 移動
- SPACE: 通常攻撃（押している間は範囲を表示し、離すと攻撃）
- 1～8: 装備したアクティブスキル
- C: NPCとの会話
- E: 施設（店、鍛冶屋、クエスト看板）の利用
- V: パーティー一覧／パーティー管理画面
- T: チャット画面
- I: インベントリ
- S: 装備画面
- P: ステータス割り振り
- Q: クエストログ
- K: スキル管理
- R: 転生画面
- O: 設定
- M: サイドメニュー
- ESC: 開いているウィンドウを閉じる
- D: 対象マップで敵AIのデバッグ表示
- Shift+T: 敵AIの学習モード切替
- Shift+@ または Ctrl+Alt+A: 開発用adminパネル

======================================================================
3. キャラクター育成・戦闘
======================================================================
- 基本能力値: STR / INT / VIT / MEN / DEX / AGI。
  STR・INTは職業に応じて攻撃力、VITはHP・防御、MENはMP、DEXは会心・速度、
  AGIは回避に影響する。
- レベルアップで経験値、HP/MP、ステータスポイントなどが成長。
- 通常攻撃は職業ごとに射程・攻撃速度・単体／範囲の特性が異なる。
- スキルにはMP消費、クールダウン、レベル、射程、範囲、属性、状態異常などを設定可能。
- 状態異常: 凍結、麻痺、毒。装備・属性・スキルによって付与可能。
- 会心、吸収、回避、即死効果、属性固定ダメージ、敵防御による軽減を実装。
- 召喚獣: 召喚、強化召喚、召喚獣への突撃命令、同時召喚数増加パッシブを実装。
- 消耗品をクイックスロットに装備でき、HP／MP回復アイテムを使用可能。

======================================================================
4. 職業・スキル
======================================================================
基本職（6職）
- ファイター: 近接の攻防バランス型
- メイジ: 高火力の魔法型
- タンク: 高HP・高防御の防御型
- レンジャー: 高速・遠距離型
- サモナー: 召喚獣を使役する魔法型
- プリースト: 回復・味方強化型

上位職
- 各基本職からLv50以降に4系統へ転職可能（計24上位職）。
- 例: ファイター→ナイト／バーサーカー／サムライ／ドラゴンナイト
- メイジ→アークメイジ／エレメンタリスト／ウォーロック／セージ
- タンク→パラディン／ウォーデン／アヴェンジャー／ジャガーノート
- レンジャー→スナイパー／ニンジャ／ガンスリンガー／ウィンドアーチャー
- サモナー→ハイサモナー／ネクロマンサー／ビーストロード／スピリットマスター
- プリースト→エクソシスト／セイント／ウォープリースト／シャドウプリースト
- 上位職は基本職の習得済みスキルを継承し、専用スキルを追加習得。

スキル分類
- 近接／遠距離／範囲／単体攻撃
- 回復、攻撃・防御・速度バフ、召喚強化
- パッシブ（攻撃・防御・HP/MP・会心・速度・経験値・召喚数・MP消費などを補正）
- 火・水・雷・風・土・光・闇の属性スキル
- 上位職専用の攻撃、オーラ、自己強化、範囲支援スキル

======================================================================
5. 装備・アイテム・属性・鍛冶
======================================================================
- 装備枠: 武器、防具、宝具（アクセサリー）。
- 装備レベル条件と、レベル不足時の性能低下を実装。
- アイテム種別: 武器、防具、アクセサリー、消耗品、素材、魔石、属性玉など。
- 店で武器・防具・雑貨・ギルド系アイテムを購入可能。
- 回復薬、MP回復薬、パーティー全体回復アイテム、能力値を永続上昇させる種などを実装。
- 鍛冶屋で武器／防具に属性を付与可能。付与した属性は耐性・追加ダメージ・状態異常に反映。

属性
- 火、水、雷、風、土、光、闇の7属性。
- 相性: 火→土→風→雷→水→火、光⇔闇。
- 有利属性はダメージ増加、不利属性はダメージ減少。
- 水: 凍結、雷: 麻痺、土: 毒の武器追加効果を持つ。

======================================================================
6. クエスト・マップ・施設
======================================================================
クエスト
- NPC会話、敵討伐、ボス討伐などのクエストを実装。
- 受注中、達成済み（報告待ち）、報告済みを管理。
- クエストの完了状況により、次のクエスト／転移先／マップが解放される。
- Qのクエストログで進行中の内容を確認可能。
- ギルドのクエスト看板から受注・報告可能。上下キー＋Enter、またはクリックで操作。

マップ（assets/maps の内容）
- tutorial: チュートリアル
- battle: ボス戦マップ
- city: 中央都市
- guild1f / guild2f: ギルド1階／2階
- forest: 森
- wetland: 湿地
- volcano: 火山
- snow_city: 雪原都市フロストヘイヴン
- desert_city: 砂漠都市サンドリア
- port_city: 港都市マリーナ

主な敵
- スライム、森林スライム、コウモリ、湿地コウモリ、スケルトン、赤スライム、
  ゴブリン、ゴースト、オーク、ダイアウルフ
- ボス: tutorial boss、forest_boss、swamp_boss、dragon_boss
- サーバー側AIによる移動・攻撃・スキル行動を実装。

施設
- 店: 武器・防具・消耗品などの購入
- 鍛冶屋: 武器／防具への属性付与
- クエスト看板: クエスト受注・報告
- ガチャ、転生、職業・スキル・装備・ステータス管理画面

======================================================================
7. マルチプレイ
======================================================================
- 同じマップのプレイヤーの位置、名前、HP/MP、レベル、召喚獣、スキル演出を同期。
- サーバー管理の敵・ボス、敵HP、撃破、経験値・ゴールド・ドロップを同期。
- パーティーメンバーにはステータスとマップをHUDで表示。
- 回復・バフ系スキルは、射程内のパーティーメンバーにも適用。
- 他プレイヤーへ回復、攻撃／防御／速度バフ、召喚強化を同期。

パーティー
- Vで「パーティー一覧」を開く。
- 未所属の状態から、公開パーティーへ自由に参加可能。
- パーティー作成時に名前を設定可能。パスワードを空欄にすると公開、入力するとパスワード保護。
- 一覧には名前、人数、リーダー、公開／鍵付き状態を表示。
- 最大人数は8人。
- リーダーのみ招待と追放（KICK）を実行可能。サーバー側でも権限を検証。
- リーダーが脱退した場合は次のメンバーにリーダー権限を移譲。
- パーティー全員が脱退するとパーティーは削除。

チャット
- TまたはサイドメニューのChatから開く。
- 全体チャット: 接続している全プレイヤーへ送信。
- チームチャット: 自分のパーティーメンバーだけへ送信。
- チャット履歴は直近100件を保持し、画面には最新12件を表示。
- パーティー未所属ではチームチャットを送信不可。

======================================================================
8. adminモード（開発・動作確認用）
======================================================================
- Shift+@ または Ctrl+Alt+Aで開く。ADMIN_CONFIG.PASSWORDが必要。
- 対象プレイヤーを自分／パーティーメンバー／同一マップの他プレイヤーから選択可能。
- 操作内容:
  レベル変更、ゴールド、ステータスポイント、ジョブEXP、魔石、HP/MP全回復、
  職業変更、全スキル習得、スキルLv最大化、アイテム付与、全装備解除、
  無敵、MP消費0・クールダウン0、マップ移動、クエスト一括操作。
- 他プレイヤーへのadmin操作はサーバーで管理パスワードを確認して中継。
- 公開運用時は client/gameConstants.js の ADMIN_CONFIG.PASSWORD と
  サーバー環境変数 ADMIN_PASSWORD を同じ安全な値に変更すること。

======================================================================
9. データ／拡張ポイント
======================================================================
- 職業: client/data/jobs.js
- スキル: client/data/skills/
- アイテム: client/data/items.js
- クエスト: client/data/quests.js
- 敵: client/data/enemyStats.js
- 属性: client/data/elements.js
- ショップ: client/data/shops.js
- 施設種別: client/data/facilities.js
- マップ: client/assets/maps/*.json（Tiledで編集）
- サーバーは assets/maps 内のJSONマップを自動検出するため、マップ追加時の定数登録は不要。

======================================================================
10. 動作確認コマンド
======================================================================
サーバーディレクトリで実行:
  npm start       : サーバー起動
  npm run check   : マップ、敵、転移、コンテンツ定義の整合性確認
