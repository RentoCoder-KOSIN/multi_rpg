# スキル偏重を抑えるための調整案

この文書は**提案のみ**です。スキル定義・ダメージ式・消費 MP などの実装値は変更していません。

## 目標

- 通常攻撃、位置取り、回復アイテム、パーティー連携にも明確な役割を持たせる。
- スキルを「常に最適な連打」ではなく、強い場面で選ぶ手段にする。
- 初心者が少ないスキルでも進行でき、スキルを覚えるほど選択肢が増える構成にする。

## 優先して検証する調整

| 項目 | 提案 | 期待する変化 |
| --- | --- | --- |
| 通常攻撃 | 敵の小さい隙や単体戦では、通常攻撃の DPS が低コストスキルと同程度になるように基礎攻撃力・硬直を調整する。 | MP 枯渇時にも戦い続けられる。 |
| MP 回復 | 非戦闘時の自然回復を上げ、戦闘中は抑える。アイテムによる即時回復は維持する。 | 連打よりも戦闘終了後の立て直しが有効になる。 |
| 範囲スキル | 最大対象数、減衰、またはクールダウンを設定する。単体相手への倍率は単体スキルを下回るようにする。 | 集団処理には強いが、ボスへの万能解を避けられる。 |
| 強力な CC | 凍結・麻痺などはボスへの効果時間を短縮し、連続付与には耐性を付ける。 | 行動不能の重ね掛けだけで勝つ状況を防ぐ。 |
| スキルレベル | Lv.1→Lv.2 の伸びを最も体感しやすくし、後半ほど伸びを緩やかにする。 | 育成初期の満足感を保ちつつ、一つのスキルへの集中投資を抑える。 |
| 敵設計 | 通常攻撃で対処しやすい小型敵、範囲スキル向きの群れ、回避・防御が重要な敵を混在させる。 | 敵に応じて行動を切り替える必要が生まれる。 |

## 検証順

1. 通常攻撃と各職の最初の攻撃スキルについて、単体 30 秒 DPS と MP 消費を記録する。
2. 同レベル帯の通常敵・群れ・ボスで、最適行動が一種類に固定されていないか確認する。
3. 強すぎるスキルは先に対象数・クールダウン・状態異常耐性で調整し、単純なダメージ下げは最後に行う。
4. 初期職から上位職まで、スキル未強化でも各エリアの推奨戦闘を突破できるかプレイテストする。

## 合格基準

- 通常攻撃のみ、またはスキルを節約した戦い方でも通常敵を無理なく倒せる。
- ボス戦で回避・距離取り・回復のいずれかが必要になる。
- 範囲、単体、支援スキルのどれにも有利な局面がある。
- 特定スキルを最大まで上げないと進めない地点がない。
